# TinyLink — Frontend URL Shortener

Built with HTML, CSS and JavaScript only.

## Features
- Long URL input
- Optional custom alias
- Demo short link generation
- Copy button
- LocalStorage history
- Delete individual links
- Clear history
- Responsive modern UI

## Run
Open `index.html` in your browser, or upload the folder to GitHub and deploy it with Vercel/Netlify/GitHub Pages.

## Important
This is a frontend-only demo. Generated `tiny.link/...` URLs are visual/demo links and are not globally registered redirect URLs.

For real public short links you need a backend + database + redirect route.
